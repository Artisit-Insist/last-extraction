# 자동 작업 종료 오류 수정 — 2026-10-02

## 원인

이 Mac의 Unreal Engine 5.8.3에서 `-ExecutePythonScript`로 작업한 뒤
`unreal.SystemLibrary.quit_editor()`를 직접 호출하면 Python 실행 도구의
완료 알림 정리 절차를 건너뛴다. 남은 Slate 알림의 글자 배치 객체가 ICU
종료 뒤 해제되면서 편집기가 충돌했다. 이후 실행된 CrashReportClientEditor도
종료 중 충돌하여 macOS 경고창이 반복되었다.

실제 기록에서 편집기는 `ubidi_close_64 → FICUTextBiDi → FTextLayout →
FSlateAsyncTaskNotificationImpl → FTSTicker` 경로로 충돌했다.
오류 보고 프로그램은 종료 시 `FScheduler::StopWorkers` 검사 실패 뒤 충돌했다.

## 적용한 수정

`Tools/editor_shutdown.py`가 화면 갱신을 잠시 유지하고
`unreal.EditorPythonScripting.set_keep_python_script_alive(False)`로
자동 실행 도구에 종료를 맡긴다. 엔진의 해당 실행 도구는 알림을 먼저
정리하고 `QUIT_EDITOR`를 예약한다. 직접 `quit_editor()`를 호출하지 않는다.
현재 제작에 사용하는 이미지·인물·소품·음악 임포트 스크립트에 적용했다.

이 도우미는 `-ExecutePythonScript` 자동 실행용이다.
언리얼 설치 파일이나 macOS 오류 알림 설정은 수정하지 않았다.
프로젝트 C++에 시도했던 전역 ticker 정리 우회 코드는 효과가 없어 제거했다.

## 확인 결과

이전에 충돌했던 음악/폭발 효과 임포트를 수정 후 두 차례 재실행했다.
두 번 모두 자료 저장 완료, 정상 종료 코드 0, 오류 보고 프로그램 미실행을 확인했다.
2026-10-02 21:35 KST 확인 시 두 검사로 새로 생긴 편집기/오류 보고 프로그램의
충돌 기록은 0건이다. 이는 해당 자동 작업 종료 문제의 검증이며 게임 전체의
안정성이나 캠페인 완성도 검증을 대신하지 않는다.

이미 표시된 macOS 창은 ‘무시’로 닫으면 된다.
