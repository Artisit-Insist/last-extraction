# 0.8 지역별 생활·작업 소품과 임무 장소

0.8은 개발 단계다. 상용 대작 수준의 그래픽과 1시간 콘텐츠가 완료되었다는 뜻은 아니다.

## 변경

새 원본 소품은 야영 천막(JungleBivouac08), 야전 진료소(FieldClinic08), 배 수리대(BoatRepair08), 마을 부엌(VillageKitchen08), 채석장 작업대(QuarryWorkbench08), 지휘 테이블(CommandTable08), 화물 수레(AirCargoTrolley08), 불탄 쉼터(BurntShelter08)의 8종이다. 천막에는 처진 천, 말뚝과 지지 줄, 야전침대를 넣었다. 수리대는 노와 구명환, 작업대는 공구판·바이스·가스통·호스, 화물 수레는 바퀴·견인봉·덮개·고정 줄을 포함한다. 완성된 원본 모델과 게임 변환 파일을 함께 보관한다.

기존 연료 탱크는 표면의 원통 각짐을 줄인 FuelStation08 사본으로 변환했다. 기존 모델은 보존했다. 새 소품의 금속 원통과 모서리에도 각도 기준 표면 노멀을 적용했다.

WorldLayout.cpp의 42개 임무 장소마다 주변 시설 조합을 직접 지정했다. 모든 장소에 반복되던 상자 줄을 없애고 모래주머니는 검문·방어 지점 위주로 남겼다. 배 수리대와 그물은 강변, 장터와 우물은 마을, 작업대와 크레인은 채석장, 화물 수레와 연료 설비는 비행장에 배치한다. 정글에는 야영지와 피해를 입은 쉼터, 요새에는 군용 장비와 진료 시설을 배치한다.

12개 호송 보급 지점의 동일한 SupplyShed를 지역별 시설로 바꾸었다. 플레이어가 무장 지점을 알아볼 수 있는 초록 표식과 소총이 놓인 보급 상자는 유지한다. 기존 길·강·교량·지역 간 이동 규칙은 유지한다.

## 원본과 재제작

- ArtSource/Production/Props08: 9개 Blender 원본, FBX, site_props_manifest.json.
- Tools/World/make_site_props.py: 새 소품 제작과 연료 탱크 사본 생성.
- Tools/World/import_site_props.py: 새 파일만 Unreal로 가져온다. 기존 강·지면 재질을 다시 만들지 않는다.
- Source/LastExtraction/WorldLayout.cpp: 42개 임무 장소의 배치.
- Source/LastExtraction/MissionFlow.cpp: 12개 호송 보급 지점의 배치.

## 확인 범위와 제한

새 메시 9개를 엔진으로 가져왔고, 여섯 지역을 실제 렌더한 화면에서 재질과 형태를 확인했다. 넓은 단일 충돌 상자로 천막 내부를 막지 않도록 실제 삼각형 표면을 정적 충돌로 사용한다. 메시는 3,132~11,964개 삼각형이며 비정상 좌표는 없다.

전달 폴더의 지역별_소품_확인.html은 실제 게임 엔진의 관찰 장면이다. 임무 장소로 카메라를 옮기고 8초 시점에 캡처했다. 포로·경비병·전투 효과와 HUD를 포함하나 일반 진행을 녹화한 영상은 아니다. 관찰 중 주인공에게 무적을 적용했다. 일반 게임 플레이 규칙을 사용하는 별도의 전체 경로 검사와 구분한다.

소품은 직접 만든 실시간 게임용 모델이다. 이 개선으로 상용 대작 수준의 세밀함이 확보되었다고 주장하지 않는다. 큰 배치 틀과 적의 원형 배치·추적 전술은 아직 추가 개선 대상이며, 새 시설 모두가 별도 상호작용 기능을 가진 것은 아니다.

## 패키징 앱 전체 검사

Mac arm64 빌드와 strict/deep 서명 검사 통과. 42개 임무 장소, 12개 호송 지점이 실제 실행에 생성되었다. 12명 구출·호송·무장, 13명 전원 헬기 탑승과 이륙을 통과했다. 구출 전후 복장 일치 12/12. 적 420명 제압, 사망 0회, 무기 낙하 로그 400개 이상. 동료 지원 사격도 발생했다.

경로 시작 오류 0, 일시적인 장애물 접촉 2회(모두 다음 위치 기록에서 이동 재개 확인), 경로 재시도 1회, VSM 넘침 0. 사용자 저장 두 파일은 검사 전후 SHA-256이 같았다. 자동 진행 1203.4초, 실제 검사 경과 705.43초이며 사람의 1시간 플레이나 실시간 FPS 검사가 아니다.

원시 결과는 PROPS_08_RESULTS.json을 참조한다.

실시간 성능은 이 Mac에서 1280×720 창 모드로 두 지역의 시작 구간을 각각 약 17초 측정했다. 최초 180프레임을 제외한 지역별 1,020프레임 기준으로 1지역 평균 55.6fps / 99백분위 프레임 시간 21.64ms, 5지역 평균 61.0fps / 99백분위 프레임 시간 16.75ms. 기본 상한은 61fps이며 캠페인 전체 성능을 보장하는 측정은 아니다.
