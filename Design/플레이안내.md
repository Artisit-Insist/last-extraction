# LAST EXTRACTION 0.9 플레이 안내

`게임시작.command`를 더블클릭하면 게임이 열립니다. 별도로 코드를 복사하거나 입력할 필요가 없습니다. 앱은 `MacGame/LastExtraction.app`에 있습니다.

시작 화면에서 Enter는 새 게임, C는 저장한 작전 이어하기입니다. 임무를 마치거나 포로를 풀어주면 자동 저장합니다. 이동 중에는 Esc로 일시정지한 뒤 Q를 누르면 현재 위치와 호송 중인 동료를 저장하고 메뉴로 돌아갑니다.

| 행동 | 키 |
|---|---|
| 이동 | W A S D 또는 방향키 |
| 목적지로 이동 | 마우스 오른쪽 클릭 |
| 조준 / 사격 | 마우스 이동 / 왼쪽 클릭 |
| 소총 / 활 | 1 / 2 |
| 재장전 | R |
| 구출·폭약 설치·문서 회수 | 가까이에서 E 길게 누르기 |
| 무전기 방어 시작 | 무전기 근처에서 E |
| 달리기 / 회피 | Shift / Space |
| 수류탄 / 응급 처치 | G / Q |
| 큰 지도 / 일시정지 | Tab / Esc |
| 음악 / 효과음 크기 변경 | F5 / F6 |

## 포로를 구출하는 방법

1. 포로 주변의 경비병을 제압하고 가까이에서 E를 길게 눌러 풀어줍니다.
2. 초록색 표식이 있는 보급 지점까지 동료와 함께 이동합니다. 적이 가까이 있고 주인공이 너무 멀어지면 동료가 기다리므로, 되돌아가 가까이에서 엄호하십시오.
3. 두 사람 모두 보급 지점에 도착하면 E를 길게 눌러 무장시킵니다. 그때 구출 임무가 완료되고, 동료가 소총으로 지원 사격을 시작합니다.

`동료_호송과_무장.mp4`에서 실제 게임 안의 이 과정을 볼 수 있습니다. 17초짜리 검토 영상이며, 자동 조작으로 녹화했습니다. 영상 효과음은 게임에서 쓰는 원본 소리를 실제 발생 시각에 맞춰 합성했습니다.

## 지역과 전투

콘크리트·금속·천·모래주머니의 질감을 보강하고, 지역마다 숲바닥·흙길·자갈·포장도로를 구분했습니다. 강의 얕은 부분에서는 강바닥과 선착장 기둥이 비치며 물가는 젖은 흙으로 이어집니다. `재질비교.html`을 열면 이전 버전과 같은 위치에서 비교할 수 있습니다.

지역별로 길과 건물 배치가 달라졌습니다. 강에서는 기관사를 구출하고 전력을 차단한 뒤 통제문을 열어 교량을 건넙니다. 채석장의 깊은 구덩이는 주변 길로 돌아가야 합니다. 요새는 중정 사이의 통로를 이용하고, 마지막 비행장에서는 모든 임무를 마친 뒤 헬기장으로 이동합니다.

보급 지점에서 무장한 동료는 소총으로 주변 적을 함께 공격합니다. 머리 위에 ‘동료’라고 표시되며 자동으로 따라옵니다. 마지막 헬기장에서 E를 누르면 구출 인원과 주인공이 헬기에 탑승해 탈출하는 엔딩이 재생됩니다.

`개선화면.html`에서 6개 지역을 비교할 수 있고, `헬기_탈출_엔딩.mp4`에는 0.3에서 녹화한 실제 엔딩의 검토 영상이 있습니다. 0.4에서는 재질을 추가로 바꾸었고 탑승 동작과 장면 순서는 같습니다. 스포일러를 피하려면 엔딩 영상은 플레이 후 여십시오.

## 편집 원본과 현재 범위

`LastExtraction_편집원본.zip`에는 Unreal 프로젝트, 소스 코드, Blender 모델·리깅·동작 원본과 음악 자료가 들어 있습니다. 게임을 즐기는 데 이 파일을 편집할 필요는 없습니다.

현재 버전은 0.9.0입니다. 자세한 확인 결과는 `검증결과.md`를 참고하십시오.


0.6에서는 경비병·정찰병·중무장병과 민간인·노동자의 옷과 장비를 다르게 적용했습니다. 구출한 동료는 입고 있던 옷을 유지한 채 보급 지점에서 무장합니다. 조작법은 같습니다.

0.7에서는 피격 방향에 따라 앞·뒤·옆으로 쓰러지고, 손을 놓은 총은 바닥에 떨어집니다. `쓰러짐과_무기낙하_실제화면.mp4`는 실제 엔진의 동작을 확대해 기록한 18초 무음 검토 영상입니다. 조작법은 같습니다.

0.8에서는 임무 장소와 보급 지점에 야영·진료 천막, 배 수리대, 부엌, 작업대, 화물 수레 등을 배치했습니다. `지역별_소품_확인.html`을 열면 여섯 지역의 실제 엔진 화면을 볼 수 있습니다. 조작과 동료 무장 방법은 같습니다.

0.9에서는 경비병이 소품 뒤에 숨었다가 옆으로 나와 사격하고, 정찰병은 측면으로 이동합니다. 시야를 끊으면 마지막으로 본 위치를 수색합니다. `요새_전투_실제화면_09.mp4`와 Trailer 폴더의 영상에서 실제 실행 화면을 볼 수 있습니다.
