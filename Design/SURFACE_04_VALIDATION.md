# 0.4 표면·지면·강 개선 검증

이 단계는 개발 중인 그래픽 개선본이며 전체 제작 완료를 뜻하지 않습니다.

## 적용

- 11개 표면 자료 세트의 색상·노멀·AO/거칠기/금속성 지도 33개를 가져왔습니다. 공식 원본의 파일 크기와 MD5가 모두 일치합니다.
- 23개 소품 재질을 31개 정적 모델에 연결했습니다. 콘크리트, 회벽, 금속 도장, 천, 모래주머니가 단색으로 보이던 부분을 바꿨습니다.
- 6개 지역의 지면을 분리했습니다. 숲의 낙엽, 마을의 흙길, 채석장의 자갈, 요새와 활주로의 아스팔트를 사용합니다. 반복 무늬가 덜 보이도록 서로 다른 크기와 각도의 재질을 혼합합니다.
- 강에는 Unreal Single Layer Water를 적용했습니다. 수심에 따른 빛의 흡수·산란, 반사, 잔물결과 물가의 젖은 흙을 연결했습니다. 얕은 곳에서 선착장 기둥과 강바닥이 보입니다.
- 파랗게 보이던 신발은 원본 이미지의 명암을 유지하면서 어두운 가죽 재질로 바꿨습니다. 원본 이미지는 변경하지 않았습니다.
- 기존 0.3 재질 자산을 보존했습니다. 제작 스크립트는 Tools/Surfaces, 원본 표면 자료는 ArtSource/Production/Surface04에 있습니다.

## 실행 확인

- 6개 지역의 실제 엔진 확대 화면, 교량, 인물, 헬기 탑승과 이륙을 확인했습니다.
- 물 셰이더를 다시 만들 때 중복 노드가 남던 오류를 수정했습니다. 재제작 스크립트는 노드 목록의 복사본을 이용해 정리하며 빈 그래프를 확인한 뒤 새 연결을 만듭니다.
- 최종 강변·교량 실행 로그에 재질 컴파일 실패가 없었습니다.
- 45.03초 엔딩에서 탑승 인원 13명, 이륙 후 기체에 연결된 인물 13명을 확인했습니다.
- Mac arm64 패키징 및 엄격한 코드 서명 검사를 통과했습니다.
- 배포 앱 전체 캠페인 검사에서 6개 지역·42개 임무, 사망 0회, 적 364명 제압을 확인했습니다. 동료 지원 사격 240회 이상과 엔딩 13명 탑승도 통과했습니다. 가속 시뮬레이션 시간은 1070.6초입니다. 세부 결과는 SURFACE_04_RESULTS.json, 원본 압축 검사 결과는 전달 폴더의 검증결과.md에 기록합니다.

## 남은 작업

상용 대작 수준의 인물·배경 완성도와 실제 1시간 분량은 달성하지 못했습니다. 특히 같은 인물 체형의 반복, 단순한 장비 형태, 먼 배경과 빈 공간, 임무 종류·전투 전술·활 전용 동작을 계속 개선해야 합니다. 자동 진행 시간은 사람의 플레이 시간이나 실제 FPS 수치가 아닙니다.
