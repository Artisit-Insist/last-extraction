# 지역·지원 동료·탈출 엔딩 개선 기록 (0.3)

## 구현

- 정글 굽이길 / 양안 교량 / 마을 격자 골목 / 중앙 굴착장을 우회하는 채석장 / 여러 중정의 요새 / 활주로와 격납고를 가진 비행장으로 이동 구조 분리.
- 휘어진 강둑과 변화하는 강폭, 작은 수면 파형, 강변 바위·배·선착장·어망.
- 기존 거점의 동일 오두막·모래주머니 묶음을 제거하고 지역별 건물·물자 구성 적용.
- 현수교·통제문·크레인 및 헬기·지역 소품·건물의 편집 가능한 Blender 원본 포함.
- 시장 가판의 천막색·크기·각도·간격, 마을 상점의 벽색에 배치별 변주 적용.
- 포로는 비무장 대기 자세, 구출 이후에는 소총을 든 지원 NPC. 경로 탐색으로 장애물과 강을 돌아 이동하며 시야 내 적에게 지원 사격.
- 저장 후 다시 시작해도 현재 지역에서 구출한 지원 NPC를 복원. 이전 저장에 구출 인원 수가 없으면 완료한 임무로 계산.
- 마지막 탈출 지점에서 45초 실시간 엔딩: 착륙 → 12명의 구출 인원과 주인공 탑승 → 일부 탑승자 착석 → 문 닫힘 → 이륙·비행. 탑승자 13명을 실제 기체에 붙여 함께 이동.
- 외부 풍경, 구조 헬기 소리, Homeward 음악 연결. 탑승 인물은 기체 이동 때문에 제자리에서 걷지 않도록 상대 이동으로 동작 계산.

## 중간 검증

- 최신 지원 사격 사거리에서 전체 42개 임무 자동 검사 PASS: elapsed=1078.8, deaths=0, kills=365. 화면을 끈 가속 실행이며 사람의 플레이 시간과 다름.
- 지원 사격 로그 280회 이상. 구출 후 이동과 교전의 실제 화면 22.03초 촬영.
- 6개 지역 전체 구조와 강의 실제 렌더링을 각각 확인.
- 기체 내부 유지 버전 엔딩의 렌더링 완료: boarded=13, total=13, aboard_actors=13, duration=45.03.
- 이후 먼 배경 지형과 먼 바위가 불필요하게 그림자 계산을 차지하는 문제를 수정. 배경과 실제 플레이 지형의 그림자 계산 분리.
- 배경 분리만으로는 근접 탑승 화면의 VSM 경고가 완전히 사라지지 않아, 일반 메시의 coarse shadow pages를 제외하고 방향광 그림자 밀도를 기본 균형값 0으로 조정. 45초 전체 재촬영에서 VSM 경고·오류 없음, 탑승 13명 유지 확인. 엔진 경고 표시 자체는 끄지 않음.
- 근거: https://dev.epicgames.com/documentation/en-us/unreal-engine/virtual-shadow-maps-in-unreal-engine 및 설치된 UE 5.8 VirtualShadowMapArray.cpp / VirtualShadowMapClipmap.cpp.

## 한계

상용 대작 수준의 그래픽이나 1시간 캠페인 완성으로 평가하지 않음. 현재 자동 진행 시간은 약 18분이며 사람의 플레이를 계측한 결과가 아님. 동료는 현재 지원 사격·추적에 초점을 맞춘 NPC로, 별도 명령 메뉴나 복잡한 분대 전술은 없음. 일부 근접 자세, 활 전용 자세, 인물 다양성, 추가 콘텐츠와 난이도 조정은 후속 개선 대상.
