# Mission 0.5 — 호송과 동료 이동 검증

## 변경

12개 구출 임무를 포로 해방 → 무장하지 않은 동료 호송 → 보급 지점에서 E로 무장 → 자동 지원 사격으로 연결했습니다. 근처의 경계 중인 적과 주인공의 거리를 보고 동료가 기다리며, HUD와 지도에 호송 대상과 보급 지점을 표시합니다. 동료 체력이나 부상 치료 시스템은 이번 변경에 포함하지 않았습니다.

저장 파일 버전 2는 임무 단계, 호송 중인 인물과 주인공의 위치를 보관합니다. 예전 저장 파일의 완료 임무도 읽을 수 있습니다. 완료한 임무의 경비병이 생략돼도 식생 배치가 달라지지 않도록 배치용 난수와 시작 지점 기준을 고정했습니다. 완료 소품의 보이지 않는 충돌도 제거했습니다.

동료가 경로 모퉁이를 돌 때 각 지점에 도달하도록 하고, 실제 이동 구간에 몸 크기의 충돌 검사를 추가했습니다. 목적지가 상자 안이면 인접한 빈 지점을 선택합니다. 폭발의 평면 시각 효과에는 충돌과 겹침 검사를 모두 끕니다.

## 현재 확인

- 호송 중 910.4 cm 이동한 지점에서 저장 → 종료 → 복원 → 무장 완료 통과.
- 저장 전후 고정 소품 2,989개, 배치 해시 8ec4aeb3 일치.
- 실제 사용자 Campaign.json의 SHA-256 불변. 검사에는 CampaignTest.json 사용.
- 첫 전체 엔진 검사: 42개 임무 / 12개 호송 / 13명 탑승, 1,291.4초, 사망 0회. 이 검사 뒤에 동료 충돌을 추가로 보강했습니다.
- Mac arm64 패키징 및 codesign 검사 통과. 최종 패키지에서도 42개 임무, 12개 호송, 13명 실제 탑승을 통과했습니다. 1,232.0초, 사망 0회, 적 419명 제압, 지원 사격 280회 이상을 기록했습니다.
- 실제 엔진 호송 영상 17.133초, 514프레임, 1280×720/30fps H.264 + AAC 44.1kHz. 전체 디코딩 통과. 효과음은 게임 이벤트 시각에 원본 WAV를 합성했으며 스피커 출력을 녹음한 것이 아닙니다.

최종 패키지 검사에서 경로 시작 위치 겹침 오류 0회, 이동 충돌 경고 0회, VSM 넘침 경고 0회입니다. 교량 통제문이 열리는 동안 경로 재시도 1회가 있었고 이후 정상 통과했습니다. 사용자 저장 파일의 SHA-256은 변하지 않았습니다.

고정 시간 간격을 사용한 가속 진행 검사이며, 1,232초는 사람의 플레이 시간이나 실제 프레임 성능을 뜻하지 않습니다.

이 자료는 개발 버전 검증이며, 1시간 플레이나 상용 대작급 그래픽을 완료했다고 표시하지 않습니다.

## 실제 시간 성능 표본

최종 arm64 배포 앱을 고정 시간 간격 없이 실행했습니다. 1280×720 창 설정, 기본 프레임 제한 약 61fps입니다. 시작 180프레임을 제외하고 각 1,020프레임을 측정했습니다.

| 지역 | 평균 FPS | 평균 프레임 시간 | 99백분위 프레임 시간 | 표본 시간 |
|---|---:|---:|---:|---:|
| 정글 | 60.99 | 16.396 ms | 16.719 ms | 16.72초 |
| 요새 | 60.99 | 16.397 ms | 16.706 ms | 16.73초 |

이 Mac에서 측정한 짧은 구간의 결과이며, 전체 캠페인 내내 같은 성능을 보장하는 수치는 아닙니다.
