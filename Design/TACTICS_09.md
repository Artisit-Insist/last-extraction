# 0.9 전투 행동 개선

경비병을 모든 목표의 원형 둘레에 놓던 배치를 지역별 초소·후방·순찰 위치로 바꾼다. 기본 적 수와 목표 종류는 유지한다.

일반 경비병은 근처의 충돌 가능한 소품을 엄폐 후보로 사용한다. 가려지는 위치와 실제로 사선이 열리는 위치를 검사하고, 두 위치 사이를 오가며 사격한다. 계속 숨어 진행이 멈추지 않도록 두 차례 사격 후 이동하며, 도달하지 못한 엄폐 위치도 일정 시간 후 포기한다. 정찰병은 한쪽 측면으로 돌아 잠시 멈추어 사격하고 중화기병은 긴 간격의 단발 대신 짧은 3발 연사를 사용한다.

총소리와 피격은 마지막으로 알려진 위치를 전달한다. 시야가 끊기면 그 위치를 수색한다. 벽 너머의 플레이어 위치를 계속 갱신하여 따라가는 방식은 사용하지 않는다. 실제 발사는 현재 시야와 총구 앞 장애물 검사를 통과해야 한다.

경로는 기존 지형·충돌 검사를 사용한다. 여러 적이 동시에 비싼 경로 탐색을 요청하지 않도록 요청을 분산한다. 초기 배치에서는 발끝부터 머리까지의 몸통 충돌을 검사한다. 지형 생성 이후의 초기 겹침도 확인하며, 전투 도중 순간 이동으로 해결하지 않는다.

이번 단계는 전투 행동과 배치의 개선이다. 인물의 무릎을 굽히는 새 엄폐 동작을 만들거나 인간과 같은 전술을 구현했다는 뜻은 아니다. 서 있는 키를 가려주는 소품의 뒤와 가장자리로 이동한다. 실제 1시간 플레이 분량과 상용 대작 수준의 그래픽은 아직 별도 검증 대상이다.

## 실제 검사 결과

Mac arm64 패키징 앱에서 6개 지역·42개 임무, 동료 12명 구출·호송·무장, 13명 헬기 탑승과 탈출을 통과했다. 적 421명 제압, 사망 0회. 행동 전환 기록은 엄폐 109회, 가장자리로 이동 24회, 측면 이동 112회, 마지막 위치 수색 132회다. 중화기병 사격 로그 4회가 기록되었다. 이 수치는 동작 전환 횟수이며, 모든 엄폐 시도가 성공적으로 끝났다는 의미는 아니다.

경로 시작 오류 0. 일시적인 장애물 접촉 1회는 이후 위치 기록에서 이동이 재개됨을 확인했다. 경로 재시도 3회. 사용자 저장 두 파일은 검사 전후 해시가 같다. 검사에 사용한 소스·설정·콘텐츠의 해시도 이후 변경되지 않았음을 확인했다.

전체 검사의 시뮬레이션 시간은 1136.9초이며 실제 검사 경과는 369.32초다. 자동 조준과 이미 알려진 경로로 수행한 검사로, 사람의 1시간 플레이 분량을 입증하지 않는다.

실시간 성능은 1280×720에서 두 지역의 시작 구간을 측정했다. 처음 180프레임을 제외하고 각 1,020프레임을 사용했다. 1지역 평균 61.0fps / 99백분위 프레임 시간 16.72ms, 5지역 평균 61.0fps / 99백분위 프레임 시간 16.81ms. 기본 상한은 61fps이며 캠페인 전체의 프레임 유지 보장은 아니다.

요새 전투 검토 영상은 실제 게임 화면 661프레임(30fps), 약 22초다. 앞선 세 임무를 완료한 상태에서 기본 카메라로 자동 조작했다. 효과음은 실제 발생한 61개 소리 기록에 맞추어 원본을 합성했고, Contact 음악을 더했다. 실제 스피커 출력 녹음은 아니다.

트레일러 뒷부분도 이 0.9 영상의 16초로 교체했다. 기존 Higgsfield 시네마틱 24초와 제목 3.2초를 유지했다. 추가 유료 생성은 없다. 최종 MP4 전체 디코드와 Blender 편집 원본의 8개 참조 파일 검사를 통과했다.
