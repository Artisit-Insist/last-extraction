# 표면 재질 편집 원본

실제 게임에는 Content/Production/Materials04 재질을 사용합니다. ArtSource/Production/Surface04에 원본 이미지와 출처·파일 검사값이 있습니다.

Unreal Editor의 재질 편집기에서 M04_ 접두사의 재질을 열면 색상, 표면 요철, 거칠기와 금속성 연결을 수정할 수 있습니다. 모델과 함께 움직이는 좌표를 사용해 헬기에 무늬가 미끄러지지 않게 했습니다.

제작자용 import_pbr_surfaces.py는 33개 원본 이미지를 가져와 재질을 다시 만들고 해당 모델에 연결합니다. 수작업 수정본은 다른 이름으로 먼저 보관해야 합니다. 일반 게임 실행에는 필요하지 않습니다.

추가 재질 M04_River는 수심에 따른 빛의 흡수·산란을, M04_CombatBoots는 신발의 가죽 색을 담당합니다. 강둑은 지면 높이에 따라 숲 재질과 젖은 흙을 섞습니다. 기존 0.3 재질은 비교용으로 보존되어 있습니다.
