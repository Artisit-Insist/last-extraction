# Motion capture source

The walking and running leg motion is retargeted from Carnegie Mellon University's motion capture database, subjects 07/09, clips 07_01 and 09_01. The original ASF/AMC files are preserved in this folder. The final character, skeleton, weapon poses, directional variants, loops and action animations are project-specific work.

- Database: https://mocap.cs.cmu.edu/
- Use information: https://mocap.cs.cmu.edu/info.php
- FAQ: https://mocap.cs.cmu.edu/faqs.php
- Source files: https://mocap.cs.cmu.edu/subjects/07/07.asf ; https://mocap.cs.cmu.edu/subjects/07/07_01.amc ; https://mocap.cs.cmu.edu/subjects/09/09.asf ; https://mocap.cs.cmu.edu/subjects/09/09_01.amc

The database permits use in commercial products. Do not resell the unmodified motion-capture database itself. See the linked source for the full terms.

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.
